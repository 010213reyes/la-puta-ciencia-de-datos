# Analisis facil de datos

Material y actividades de Ciencia de Datos del 9.º semestre.

## Contenido

- `S4_limpieza_datos_ALUMNO.ipynb`: limpieza y procesamiento con pandas desde CSV, JSON y SQLite.
- `S4_revision_amazon_ALUMNO.ipynb`: limpieza y análisis estadístico del dataset de Amazon.
- `actividad_bayes_probabilidad (1).ipynb`: actividad de probabilidad y Bayes.
- Archivos CSV, JSON y SQLite usados por las actividades.

## Entorno

El proyecto usa un entorno virtual en `.venv`, excluido del repositorio.

```powershell
.\.venv\Scripts\Activate.ps1
```

Dependencias principales: NumPy, pandas, Matplotlib, seaborn, SciPy, scikit-learn y Jupyter.
